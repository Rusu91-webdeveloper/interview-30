## Rules
1. One topic per day, 3-4 hours.
2. Start with a 20-minute closed-book quiz (cards from 1, 3, 7 and 14 days ago).
3. 25-minute hand-written attempt before any help. Then AI only as a tutor: conceptual questions, no code. Log it in `ai-log.md`.
4. One 15-minute code-trace task per day.
5. Every exercise ships with tests (from Day 3).
6. One branch + one PR per day. Self-review before merging.
7. End the day with 5 new quiz cards and a 2-minute spoken explanation in English.
